# VRChat Credit Converter 🎮💰

A modern, fast, and SEO-optimized web application for converting VRChat credits (VRC) to real-world currencies with live exchange rates.

## 🌟 Features

- **Real-time Currency Conversion**: Convert VRC credits to 170+ world currencies
- **Monthly Earnings Calculator**: Calculate potential earnings from VRChat subscriptions
- **Live Exchange Rates**: Updated currency rates using Open Exchange Rates API
- **Revenue Breakdown**: See exactly how VRChat revenue is split between creators, platforms, and VRChat
- **Progressive Web App**: Install on mobile devices for offline access
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **SEO Optimized**: Structured data, proper meta tags, and fast loading times

## 📊 How VRChat Revenue Works

When users purchase VRChat credits that go to creators:
- **50%** goes to content creators
- **30%** goes to platform stores (Steam, Oculus, etc.)
- **17.1%** goes to VRChat
- **2.9%** goes to Tilia (payment processor)

## 🔧 Installation & Setup

1. Clone the repository
2. Get your API key from [Open Exchange Rates](https://openexchangerates.org/)
3. Replace the API key in `script.js`
4. Deploy to your web server
